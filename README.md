# СлойМастер 3D

Локальная FDM-студия: анализ 3D-моделей, подбор стартовых настроек и подготовка проекта для слайсера.

**[Скачать последний выпуск](https://github.com/kirillpanovk-collab/sloymaster-3d/releases/latest/download/SloyMaster3D-1.2.0-portable.zip)** · [Все выпуски](https://github.com/kirillpanovk-collab/sloymaster-3d/releases) · [Лицензия](LICENSE_RU.txt)

## Возможности

- Читает STL, 3MF, OBJ, PLY, AMF, OFF, glTF 2.0 и GLB.
- Анализирует габариты, площадь, объём, нависания и пятно контакта; проверяет целостность сетки ограниченным набором эвристик.
- Сравнивает шесть направлений укладки с учётом выбранной цели: скорость, меньше поддержек, прочность или качество.
- На Windows ищет установленные слайсеры, очереди принтеров, COM-порты и сохранённые профили-кандидаты; локальные сетевые объявления принтеров проверяет через SSDP/UPnP и mDNS.
- Запоминает профиль принтера и расширенные настройки: высоту слоёв, стенки, заполнение, поддержки, температуры, скорость и кайму.
- Подготавливает ориентированную модель и 3MF-проект с профилями для OrcaSlicer, Bambu Studio или PrusaSlicer, затем открывает его для проверки.
- Хранит журнал печати локально; содержит четыре экспертных модуля на правилах, а не облачных ИИ-агентов.
- Предоставляет лицензию правообладателя и HTTPS-ленту обновлений.

## Установка

1. Скачайте ZIP из [раздела Releases](https://github.com/kirillpanovk-collab/sloymaster-3d/releases).
2. Распакуйте весь архив в одну папку на Windows 10/11.
3. Запустите `Start-SloyMaster.cmd`. Для отдельного ярлыка с иконкой один раз запустите `Create-Desktop-Shortcut.ps1`. Требуется Microsoft Edge.

## Точность и ограничения

Windows-очередь, USB/COM-порт, сетевое объявление и локальный профиль помогают подобрать конфигурацию, но сами по себе не подтверждают, что физический принтер готов к печати. Сетевой поиск ограничен multicast-объявлениями текущей сети и не перебирает IP-адреса. Если найдено несколько профилей, приложение запоминает ваш выбор; единственный подходящий кандидат подставляет автоматически.

Подготовка проекта настроек реализована для односопловых профилей OrcaSlicer, Bambu Studio и PrusaSlicer. Другие найденные слайсеры доступны для ручного переноса рекомендаций; форматы настроек разных программ несовместимы. Мультиэкструдерные профили пока не передаются автоматически. Проект 3MF открывается в слайсере — приложение не создаёт G-code и не отправляет задание на принтер.

Ориентация — эвристическая оценка геометрии. Она не знает направления нагрузок детали, свойств конкретной катушки или состояния принтера. Сверьте материал, температуры, поддержки и предпросмотр перед печатью.

## Приватность

При запуске выполняется локальный поиск принтеров объявлениями SSDP/mDNS; адреса найденных устройств остаются на компьютере. Сканирования IP-диапазонов, входа в принтер и отправки заданий нет. При нажатии «Подготовить проект» модель передаётся локальному помощнику на адресе `127.0.0.1`, затем выбранному слайсеру. Файлы остаются в `%LOCALAPPDATA%\SloyMaster3D\PreparedProjects` и могут быть удалены вручную. Модель и журнал печати не отправляются в интернет. Обратная связь, если настроена, отправляется только отдельным действием после предварительного просмотра и согласия.
