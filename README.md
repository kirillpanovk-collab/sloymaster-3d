# СлойМастер 3D

Локальная FDM-студия для анализа 3D-моделей, стартовых настроек и результатов печати.

**Правообладатель:** Панов Кирилл Александрович · © 2026

[Скачать последнюю версию](https://github.com/kirillpanovk-collab/sloymaster-3d/releases/latest/download/SloyMaster3D-1.0.1-portable.zip) · [Лицензия](LICENSE_RU.txt)

## Что умеет

- Читает STL, 3MF, OBJ, PLY, AMF, OFF, glTF 2.0 и GLB.
- Анализирует размеры, площадь/объём сетки, нависания, пятно контакта и ограниченно проверяет целостность рёбер.
- Даёт стартовые рекомендации по материалам, целям печати и указанным пределам принтера.
- На Windows показывает доступные очереди, COM-порты, слайсеры и профили; обнаружение не подтверждает физическое подключение или совместимость любого принтера.
- Ведёт локальную историю исходов печати и показывает осторожные ориентиры после трёх успешных примеров для одной связки принтера, филамента и сопла.
- Включает четыре локальных экспертных модуля на правилах. Это не облачные ИИ-агенты.
- Проверяет HTTPS-манифест обновлений при запуске не чаще раза в сутки; скачивание и установка остаются ручными.

## Установка

1. Скачайте ZIP из [раздела Releases](https://github.com/kirillpanovk-collab/sloymaster-3d/releases).
2. Распакуйте его на Windows 10/11.
3. Запустите `Start-SloyMaster.cmd` (нужен Microsoft Edge). При первом запуске примите лицензию.

## Приватность и ограничения

Файлы моделей и журнал печатей остаются на компьютере. Приложение не наблюдает за физической печатью, не создаёт G-code и не управляет принтером/слайсером. Стартовые значения не заменяют профиль слайсера и технический паспорт конкретной катушки.
