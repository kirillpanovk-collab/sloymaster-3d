СЛОЙМАСТЕР 3D — ПЕРЕНОСИМЫЙ ПАКЕТ 1.0.1

ЗАПУСК
1. Распакуйте архив в отдельную папку.
2. На Windows 10/11 запустите Start-SloyMaster.cmd.
3. Для передачи доступных сведений Windows нужен Microsoft Edge.

ВОЗМОЖНОСТИ
• Анализ STL, 3MF, OBJ, PLY, AMF, OFF, glTF 2.0 и GLB.
• Подсказки по материалу, геометрии и ограничениям принтера.
• Четыре локальных экспертных модуля; это правила, а не генеративные ИИ-агенты.
• Журнал результатов и локальные ориентиры по фактическим настройкам.
• Принятие лицензионного соглашения при первом запуске.

ПРИВАТНОСТЬ И ГРАНИЦЫ
Модели и журнал печати остаются на этом компьютере. Приложение не следит за печатью и не управляет принтером/слайсером. Сетевая проверка обращается только к публичному JSON-манифесту обновлений; модели и история не отправляются. Загрузка и установка обновлений выполняются вручную.

Это переносимое веб-приложение в режиме Microsoft Edge, а не установщик EXE. Стартовые значения не заменяют профиль слайсера и техпаспорт конкретной катушки.
